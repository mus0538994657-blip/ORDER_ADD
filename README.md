# نظام إدارة طلبات ورشة تركيب زجاج المركبات

نظام Flask لإدارة طلبات تركيب/تبديل زجاج السيارات، يشمل: إدارة الطلبات، إدارة الأصناف (أنواع الزجاج)، وتقارير قابلة للتصدير إلى Excel.

## التشغيل

```bash
# 1. إنشاء بيئة افتراضية (اختياري لكن يُفضّل)
python3 -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. تشغيل التطبيق
python app.py
```

بعدها افتح المتصفح على: `http://localhost:5000`

عند أول تشغيل، يقوم النظام تلقائياً بـ:
- إنشاء قاعدة بيانات SQLite باسم `workshop.db`
- إضافة أصناف افتراضية (زجاج أمامي، خلفي، جانبي، فتحة سقف، تظليل زجاج) بأسعار مبدئية يمكنك تعديلها من صفحة "الأصناف"

## المزايا

- **لوحة تحكم**: إحصائيات سريعة (إجمالي الطلبات، قيد الانتظار، قيد التنفيذ، مكتملة)
- **الطلبات**: إضافة/تعديل/حذف، بيانات العميل والمركبة، تحديث سريع للحالة، بحث وفلترة
- **الأصناف**: إدارة أنواع الزجاج وأسعارها الافتراضية (تُعبّأ تلقائياً عند اختيار الصنف في الطلب)
- **التقارير**: فلترة بالتاريخ/الحالة/الصنف، إحصائيات إيرادات، وتصدير Excel منسّق (اتجاه RTL)

## البنية

```
order_system/
├── app.py                  # نقطة التشغيل الرئيسية + لوحة التحكم
├── config.py                # الإعدادات (قاعدة البيانات، حالات الطلب، اسم الورشة)
├── models.py                 # نماذج Category و Order
├── blueprints/
│   ├── orders_bp.py          # مسارات الطلبات
│   ├── categories_bp.py      # مسارات الأصناف
│   └── reports_bp.py         # التقارير وتصدير Excel
├── templates/                 # قوالب HTML (Bootstrap 5 RTL + خط Cairo)
└── static/style.css           # التنسيق
```

## نقاط للتطوير لاحقاً (اختيارية)

- تسجيل دخول للموظفين/الإدارة (Flask-Login)
- ربط رقم لوحة السيارة بسجل تاريخي لكل مركبة
- تنبيهات عبر واتساب/رسائل عند اكتمال الطلب
- طباعة فاتورة/إيصال لكل طلب (PDF)
